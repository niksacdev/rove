# ROVE notebooks

Clone ROVE to get these Jupyter learning labs. Each notebook has its own setup;
use its dedicated Python environment rather than the ROVE application environment.

| Notebook | What you can explore | Setup |
| --- | --- | --- |
| [ABC and XDOF](abc_xdof/hello_abc.ipynb) | Demonstrations, action predictions, simulator episodes and optional ABC-VLA fine-tuning. | [ABC instructions](abc_xdof/README.md) |
| [GR00T N1.7, MuJoCo and MCAP](gr00t/gr00t_n17_finetuning_mujoco_mcap_lab_v2.ipynb) | SO100 data inspection, MuJoCo, optional GR00T fine-tuning and LIBERO evaluation, and synthetic MCAP cleaning. | [GR00T instructions](gr00t/README.md) |

The notebooks are standalone exercises. GPU training and inference require the
runtime described in each guide. Notebook outputs do not automatically become
ROVE Trials or Campaigns.
