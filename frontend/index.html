Welcome to ROVE

Robot Observation & Vision Evaluation — evaluate robotics agent pipelines by running VLM+VLA+Agent combinations on manipulation tasks.

Scene Perception

VLMs analyze workspace images to detect objects, spatial relationships, and task-relevant features.

Task Planning

VLMs, LLMs, or Foundry agents reason about how to accomplish the task with step-by-step strategies.

Action Execution

VLAs, LLMs with tools, or Foundry agents execute the planned actions via trajectories or tool calls.

Automated Verification

VLMs compare before/after images to verify task completion with confidence scores and reasoning.

Get Started

1 Upload a robotics workspace image using the camera button
2 Describe a manipulation task (e.g., "Pick the red bracket and place it in bin A")
3 Select one or more strategies (pipeline configurations) to evaluate
4 Click Evaluate and compare pipeline results across strategies
